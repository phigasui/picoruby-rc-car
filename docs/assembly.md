# くみたて かた

親子で順番に進めるための手順です。各ステップに、だれが担当するかの目安を書いてあります。
- 👦 子供がやる
- 🧑 大人がやる
- 🤝 いっしょにやる

所要時間の目安: 印刷を除いて 2〜3 時間（2 回に分けてもかまいません）。

> **この手順は 2 輪版（TT モーター＋キャスター）のものです。** 4WD 版は、底板を作り直したあとで書き換えます。配線は [wiring.md](wiring.md) が 4WD 版になっています。

## じゅんび

**印刷するもの**（[README](../README.md) の「3D モデル」を参照）
- Chassis（底板）
- Body（ボディ）: 上面を下にして印刷する
- Bumper（バンパー）

**部品**: [BOM.md](BOM.md) を見て、机の上に並べておきます。小さいネジは小皿に入れておくと、なくしにくいです。

**道具**
- プラスドライバー（#1, #2）
- ラジオペンチ
- はんだごて（ステップ 1 だけ）
- 両面テープ
- USB ケーブル（micro-B）

---

## 1. DRV8833 にピンをつける 🧑
1. DRV8833 に付属のピンヘッダ（8 ピン × 2 本）を、ブレッドボードにさして立てる
2. その上に基板をのせて、全部のピンをはんだ付けする
3. 冷めたら抜く

> ブレッドボードを台にして使うと、ピンがまっすぐ付きます。

## 2. キャスターを つくって つける 🤝
1. タミヤのボールキャスターを、説明書のとおり **25mm（低いほう）** で組み立てる 👦
2. 底板を裏返し、後ろの台座（でっぱり）にキャスターをあてる
3. M3×8 のネジを 2 本、下から通す。上側でナットを締める 🤝

> ナットはラジオペンチで押さえ、ドライバーで回します。

## 3. モーターを つける 🤝
左右とも同じように付けます。
1. モーターを、底板の前の方にある壁の外側に置く。**シャフト（白い軸）は外向き**、モーターの線は車体の内側に向ける 👦
2. M3×30 のネジを、壁の内側から 壁 → モーターの穴 の順に通す（2 本）🤝
3. モーターの外側でナットを締める 🧑

> 穴の位置が合わないときは、モーターの実物をはかって `RcCarChassis.py` の `tt_hole1` / `tt_hole2` / `tt_hole_z` を直し、印刷し直します。

## 4. タイヤを つける 👦
- シャフトの平らな面と、タイヤの穴の形を合わせて、まっすぐ押し込む
- 回してみて、底板やネジに当たらないことを確かめる

## 5. バンパーを つける 👦
1. バンパーのすき間に、底板の前の端を差し
2. M3×8 のネジ 2 本を上から通して、下でナットを締める

## 6. 電池ボックスを はる 👦
1. 電池ボックスの裏に両面テープを貼る
2. 底板の後ろの枠に入れて、ぎゅっと押さえる。**スイッチは後ろ向き**にする（ボディの窓から指がとどく）
3. 電池はまだ入れない

## 7. ブレッドボードに 部品を さす 🤝
1. ブレッドボードの裏の両面テープをはがし、前の枠に貼る 👦
2. **Pico 2 WH** を、まん中の溝をまたぐように差す。USB の差し込み口は前に向ける 🤝
3. **DRV8833** を、Pico とかぶらない列に、溝をまたいで差す 🤝
4. **ダイオード**を差す。白か黒の帯がある側を、Pico の VSYS につながる列にする 🧑

> ピンが曲がらないように、ゆっくりまっすぐ押し込みます。

## 8. はいせん 🤝
[wiring.md](wiring.md) の表を大人が 1 行ずつ読み上げ、子供がジャンパー線を差します。差し終えたら、その行にチェックを入れます。

- [ ] 電池 ＋（赤） → DRV8833 VIN
- [ ] 電池 ＋（赤） → ダイオード（帯のない側）
- [ ] ダイオード（帯の側） → Pico VSYS（39 番）
- [ ] 電池 −（黒） → DRV8833 GND
- [ ] 電池 −（黒） → Pico GND（38 番）
- [ ] Pico GP16（21 番） → AIN1
- [ ] Pico GP17（22 番） → AIN2
- [ ] Pico GP18（24 番） → BIN1
- [ ] Pico GP19（25 番） → BIN2
- [ ] DRV8833 AO1 / AO2 → 左モーター
- [ ] DRV8833 BO1 / BO2 → 右モーター

> 電池の ＋ と − を逆にすると壊れます。電池を入れる前に、大人がもう一度だけ確かめてください。

## 9. うごかして みる 🤝
1. 車体を箱の上にのせて、**タイヤを浮かせる**
2. 電池を入れて、スイッチを入れる
3. USB でパソコンにつなぎ、[README](../README.md) の手順でファームを書き込む
4. `test_wiring.rb` を実行し、左右のタイヤが 前 → 後ろ の順に回るかを見る
5. `app.rb` を入れて USB を抜く。オンボード LED が点滅すれば OK

## 10. ボディを かぶせる 👦
1. 配線がはさまらないように整える
2. ボディをかぶせる。**ライトの穴が前**、窓が後ろ（電池のスイッチ側）
3. M3 のネジ 4 本を上から締める。最後に少しかたくなるところで止める（締めすぎると割れる）

## 11. はしらせる！ 👦
1. Android の Chrome で https://phigasui.github.io/picoruby-rc-car/controller/ を開く
2. 「つなぐ」を押して `KURUMA-1` を選ぶ
3. まずは 🐢 おそい で練習する

---

## こまったときは

| こまったこと | みるところ |
|---|---|
| タイヤが回らない | 電池のスイッチ、電池の向き、DRV8833 の VIN と GND |
| 前に進まず回ってしまう | 片方のモーターが逆向き → `app.rb` の `INVERT_L` / `INVERT_R` を `true` にする |
| 走ると止まる・つながりが切れる | 電池が減っている、またはダイオードが 1N4148 → 電池を替える、1N5819 にする |
| スマホに `KURUMA-1` が出てこない | 電池のスイッチ、LED が点滅しているか、スマホの位置情報と Bluetooth がオンか |
| まっすぐ走らない | 左右のモーターの個体差 → 子供と一緒に `app.rb` で調整を考えてみる |
